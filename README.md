Penjelasan tentang tugas
"Program Sistem Penilaian Akademik ini dibangun menggunakan 3 file utama terpisah (index.html, style.css, dan script.js).
HTML (index.html) menyediakan kerangka antarmuka berupa form input teks dan tabel hasil dinamis.
CSS (style.css) mempercantik tampilan agar rapi dan responsif, lengkap dengan pewarnaan predikat grade yang berbeda.
JavaScript (script.js) bertindak sebagai pusat logika program, di mana:
Menggunakan perulangan (for loop) untuk memproses deretan angka nilai yang dimasukkan pengguna secara berurutan.
Menggunakan percabangan (if-else if-else dengan 5 kondisi) untuk mengevaluasi setiap angka ke dalam predikat Grade A, B, C, D, atau E secara akurat."
